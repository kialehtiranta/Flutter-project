## Gift list application

An application where you can share your present wishes with others. The idea is to make it easier to decide what to get your friends when you are thinking a present for them. In the app see what your other friends have wished to receive. You can also add gifts you would like to receive.

### Home page (MY GIFT WISHES)

- On the left side of the application menu you can open a hamburger menu to see which account you are currently using. It also has a button to open the friend list page.
- at the home page you can see your own gift wishes and add more by clicking "Add new"-button.

### Adding new gift wish page(ADD NEW GIFT WISH)

- Opens a form where the user can add a new gift wish. The gift wish always has a name and an optional description of the gift.
- After clicking "Submit", the application asks are you sure you want to submit this wish. By clicking "OK", the app directs the user to the home page where the added gift list can be seen.

### Friend list page (MY FRIENDS)

- On this page you can see your friends and open their gift lists by clicking their name.

### Gift wishes page (GIFT WISHES)

- When you open your friends page from the friend list page, you can see the currently selected friends gift wishes.
